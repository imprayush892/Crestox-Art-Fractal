# **App Name**: Crestox

## Core Features:

- Fractal Browser: Browse art fractals by various criteria.
- Fractal Detail View: View detailed information about an art fractal and the artist.
- Artist Profiles: Artist profiles with artwork and personal details
- User Authentication: User account creation and secure login for collectors and artists
- AI Artwork Suggestion: Generate fractal artwork suggestions based on collector preferences as a tool.
- Collection Display: Personalized collection view for collectors to track their art fractals.
- Public Browsing: Allow platform browsing as logged-out user.

## Style Guidelines:

- Primary color: #1D3DA6 to convey innovation, technology, and trust.
- Background color: #FDFCF6, providing a clean, airy feel.
- Accent color: #C9D4C0, for highlighting interactive elements and calls to action.
- Headline font: 'Playfair Display' (serif) for a modern and tech-forward aesthetic. Body font: 'Inter' (sans-serif).
- Use minimalist line icons to represent various art styles and filters.
- Grid-based layout for art fractal listings, ensuring a clean and organized presentation.
- Subtle hover effects on art fractal thumbnails to provide visual feedback.
